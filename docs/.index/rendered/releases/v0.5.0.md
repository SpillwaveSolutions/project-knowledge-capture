## Change Log

- [[Ticket-01KZ75R2FPH92VY79KNR6MP59E]] Fingerprint worklog items on materialize (#9) — Compute a stable fingerprint per worklog item from the fields that actually affect the rendered concept: title, body, status, parent, wiki_key.
- [[Ticket-01KZ75R2NDYVCGERRTKE9XCRM2]] Skip unchanged ULIDs without rewriting (#10) — When an item's fingerprint matches the one recorded in its concept, skip it before reading or rendering the file.
- [[Ticket-01KZ75R2TEF13SKZYZ3DSBS5BZ]] Assert zero-write re-materialize in CI (#11) — CI already asserts a second materialize run reports '0 created'.
- [[Ticket-01KZ75R2ZJGMNBHD82WZXPCNX4]] Add Risk type with mitigates and exposes edges (#12) — Add a Risk concept type with mitigates and exposes edges, wired through TYPE_TO_DIR, CATALOGS, a template, and the curate hook's catalog list.
- [[Ticket-01KZ75R34PGN7WH6HCP44B85A2]] Add Acceptance type with verified_by edge (#13) — Add an Acceptance concept type carrying one atomic, checkable condition, linked to its Feature and to whatever proves it via verified_by.
- [[Ticket-01KZ75R39PENN65G92HKA108H3]] Cover Risk and Acceptance in sample-knowledge (#14) — Extend sample-knowledge with a Risk and an Acceptance node on the auth chain so the new types are covered by validate, doctor and the golden pack assertions like every other type.
- [[Ticket-01KZ75R3YBQAH47CYTF06A4WF0]] Adopt WikiTicket SDD in the PKC repo — PKC ships a WikiTicket bridge but did not use it, so the integration was only ever exercised against a four-item test fixture.
